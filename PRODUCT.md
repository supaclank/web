# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People who want to make websites and native mobile apps by describing their ideas. Developers and companies can also use the open-source tools with existing repositories and agent harnesses.

## Product Purpose

Clank turns a prompt into an editable app, with agent conversation and a live preview in one workspace.

## Positioning

An open-source app builder with native mobile previews, a mobile companion, and free local operation. Cloud execution is paid, with an existing seven-day trial.

## Capabilities and Constraints

The existing host supports template-based projects, persistent agent sessions, private previews, and repository imports. The web client must connect these capabilities. Web projects start with Svelte; mobile projects use the existing Expo starter. Defer anonymous accounts, mobile app redesign, collaborative canvases, and enterprise fleet orchestration.

The signed-in workspace is a pannable board. Each project node contains a chat and live preview side by side. Submitting the landing prompt opens the board in the same surface; signing in preserves the idea and board context. Multiple project conversations can remain open together. Rich reference materials and collaboration are future extensions.

## Brand Commitments

Use Clank as the product name. Keep the recognizable mascot. The requested landing page is primarily dark, clean, minimal, and uses modest text sizes. A central prompt connects to cloud/local input choices and web/mobile output choices. Cloud is selected initially. Selecting local reveals copyable Homebrew commands. A softly animated, fading dot grid sits behind the prompt.

## Evidence on Hand

Existing source code, mascot and bundled fonts, Android app distribution, local CLI, agent connections, seven-day cloud trial, Expo template and preview pipeline. Do not invent adoption numbers or customer claims.

## Product Principles

- Make building an app the first action.
- Preserve ownership of code and choice of agent.
- Keep execution, agent state, and errors understandable.
- Make native mobile and web outputs equally discoverable.
