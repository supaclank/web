# Contributing

Issues and pull requests are welcome.

1. Fork the repository and create a focused branch.
2. Run `bun install`.
3. Make the change and add or update tests where behavior changes.
4. Run `bun test` and `bun run build`.
5. Open a pull request explaining the user-visible result.

Keep pull requests small when possible. Do not include secrets, deployment credentials, private customer data, or generated build output.
